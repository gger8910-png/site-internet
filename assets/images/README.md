# Dossier Images - First Agent IA

Ce dossier est destiné à contenir les images 2D et 3D inspirées de DeepMind pour le site First Agent IA.

## Types d'images recommandées

### Images 2D
- **Icônes blanches** : Icônes minimalistes pour les fonctionnalités
- **Illustrations** : Schémas de réseaux de neurones, architectures IA
- **Diagrammes** : Visualisations de workflows de développement
- **Logos** : Logo de l'application et partenariats

### Images 3D
- **Réseaux de neurones 3D** : Rendu de structures similaires à DeepMind
- **Cubes géométriques** : Éléments 3D abstraits
- **Particules** : Effets de particules lumineuses
- **Visualisations de données** : Graphiques 3D interactifs

## Format recommandé
- **Format** : PNG (transparence), WebP (optimisé)
- **Résolution** : HD/4K pour les images principales
- **Taille** : Optimisée pour le web (< 500KB par image)
- **Couleurs** : Palette noir/bleu clair (#000000, #60a5fa, #3b82f6)

## Exemples de sources
- **DeepMind** : https://deepmind.com/research/publications
- **Unsplash** : Images gratuites de technologie
- **Freepik** : Icônes et illustrations
- **Blender** : Création 3D personnalisée

## Utilisation dans le HTML
```html
<img src="assets/images/2d/illustrations/neural-network.png" alt="Réseau de neurones" class="feature-image">
```

## Optimisation
Utilisez des outils comme:
- **TinyPNG** : Compression sans perte
- **Squoosh** : Conversion WebP
- **ImageOptim** : Optimisation avancée
